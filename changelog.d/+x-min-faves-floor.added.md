`LAST30DAYS_X_MIN_FAVES` puts a likes floor on the Apify X backend's topic search, appended as X's `min_faves:` operator alongside the existing `since:`/`until:` window. That backend bills per result, so a narrow topic whose "Top" tab is ranked off a small pool was returning small-account posts you had paid for. Unset, `0` or unparseable leaves the search term byte-identical, so no existing caller changes behaviour, and handle/mention lookups never get a floor (there the named account is the point, whatever its reach). Resolves like every other setting: skill config > process env > `API_DISPATCH_ENV_FILE`. Set it too high and X returns nothing — an empty source, not an error.
